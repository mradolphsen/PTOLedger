Sync to GitHub

Data is stored as a small JSON file in a repo you control, so it follows you between computers. Create a fine-grained personal access token scoped only to that repo with Contents: read and write permission. The token is saved only in this browser's local storage — never written into the data file — but treat it like a password, and re-generate it on each device you use.
