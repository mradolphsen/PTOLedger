Sync to GitHub

Data is stored as a small JSON file in a repo you control, so it follows you between computers. Create a fine-grained personal access token scoped only to that repo with Contents: read and write permission. The token is saved only in this browser's local storage — never written into the data file — but treat it like a password, and re-generate it on each device you use.

Synced to a private data file in your own GitHub repo — the repo itself isn't shown here since it is fixed for this copy of the page.

Correct Beginning Balance

Enter the balance that your payroll or timekeeping system shows for the beginning of this pay period. This correction becomes the starting point for this period and flows through subsequent periods. If you remove the correction, the ledger returns to its normal calculated beginning balance.
